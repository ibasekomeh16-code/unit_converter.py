⚡ Building My First Python Engineering Project!

As an ND1 Mechatronics Engineering student, I developed an Ohm's Law and Power Calculator using Python.

I chose this project because electrical calculations are important in engineering, and I wanted to understand how programming can make these calculations easier and faster.

My program calculates voltage, current, resistance, and electrical power using the appropriate formulas.

One of the challenging parts was making sure the program could handle incorrect inputs and perform calculations accurately. I worked on this by using Python functions, loops, and conditional statements.

I also added an extra feature: an electrical safety warning that alerts users when voltage exceeds a specified limit.

Through this project, I improved my understanding of Python programming, problem-solving, and the practical application of electrical engineering principles.

This is another step forward in my journey as a Mechatronics Engineering student.
