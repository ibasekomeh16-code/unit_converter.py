⚡ Building My First Python Engineering Project!


As an ND1 Mechatronics Engineering student, I developed an Engineering unit converter calculator using Python.

I chose this project because unit converter calculations are important in engineering, and I wanted to understand how programming can make these calculations easier and faster.

My program converter millimetres to inches,killograms to pounds and and my converter using the appropriate formulas.

One of the challenging parts was making sure the program could handle incorrect inputs and perform calculations accurately. I worked on this by using Python functions, loops, and conditional statements.

I also added an extra feature: Celsius to Fahrenheit and the last one is km/h to m/s.

Through this project, I improved my understanding of Python programming, problem-solving, and the practical application of units converter principles.

This is another step forward in my journey as a Mechatronics Engineering student.
